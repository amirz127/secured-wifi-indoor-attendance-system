# Problem Statement

## Project Title
Secured WiFi-Based Indoor Attendance System Using Hashing Algorithm

## Background
Student attendance is an important process in educational institutions. Traditional attendance methods, including manual attendance and online attendance systems, may allow students to record attendance without being physically present in the classroom.

## Problem
The existing attendance process may be vulnerable to proxy attendance, where a student records attendance on behalf of another student. This affects attendance accuracy and makes it difficult for lecturers to ensure that students are physically present during class sessions.

## Proposed Solution
This project proposes a secured WiFi-based indoor attendance system that uses the classroom WiFi SSID to verify network presence. The system also applies the SHA-256 hashing algorithm to Student IDs and Device IDs as part of the attendance verification process.
