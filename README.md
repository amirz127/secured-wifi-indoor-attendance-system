# Secured WiFi-Based Indoor Attendance System Using Hashing Algorithm

A WiFi-based indoor attendance system that uses classroom SSID detection and SHA-256 hashing to support student attendance verification.

## Problem Statement

Traditional attendance methods may allow proxy attendance, where students record attendance on behalf of others without being physically present in the classroom.

## Project Objectives

1. To develop an Android application that detects the registered classroom WiFi SSID.
2. To apply SHA-256 hashing to Student IDs and Device IDs as part of the attendance verification process.
3. To develop an attendance system that allows lecturers to monitor student attendance records.
